# TTCompressor
A compressor utility managing most common file formats and supporting Reed Solomon error correction. It compiles with Lazarus 4.8 and 4.0.
Please note that the 7z program is a modified version. Its source code can be found in the 7-Zip-26.04-modified.zip file, and the 7z executable must be located in the same folder as TTCompressor.
